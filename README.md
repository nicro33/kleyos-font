# Kleyos 1.0.0

Kleyos est une famille manuscrite / brush en deux variantes :

- **Kleyos Display** : titres, cartes, grands corps.
- **Kleyos Text** : petits corps et textes courts.

## Fichiers

- `fonts/ttf/Kleyos-Display.ttf`
- `fonts/ttf/Kleyos-Text.ttf`
- `fonts/woff2/Kleyos-Display.woff2`
- `fonts/woff2/Kleyos-Text.woff2`
- `css/kleyos.css`

## Installation

Installez les fichiers TTF sur macOS, Windows ou Linux, puis sélectionnez **Kleyos Display** ou **Kleyos Text** dans l'application.

## Utilisation Web

Copiez le dossier `fonts/woff2` et `css/kleyos.css` sur votre site, puis chargez la feuille CSS.

```html
<link rel="stylesheet" href="/kleyos/css/kleyos.css">
<h1 class="kleyos-display">Titre Kleyos</h1>
<p class="kleyos-text">Texte Kleyos</p>
```

## Couverture

La version 1.0.0 contient 123 caractères encodés, notamment l'alphabet latin, les accents français courants, les ligatures `æ` et `œ`, la ponctuation française, le symbole degré et les 12 symboles du zodiaque.
