FONTLOG for Kleyos

Version 1.0.0 — 2026
- First public release.
- Display and Text families.
- French accented Latin coverage.
- Zodiac symbols.
- Finalized punctuation spacing.
- Reworked diacritics.
- Capital A accents aligned optically to the apex.
- Capital Ç cedilla micro-corrected for weight and attachment.
- WOFF2 webfonts added.

Version 1.2.0 — 2026-10-28
- Published H2-i31 Assemblages with stable public family names.
- OpenType Version 1.310; no changes to i31 outlines or positioning.
- Google Fonts admission is pending; see documentation/PUBLICATION.md.

Version 1.3.0 / OpenType 1.411
Kleyos Regular is built from the editable i33 UFO. The only active family
name for the 1.3.0 package is Kleyos. The publicly packaged spacing matches
i33 Display. The 1.2.0 fonts remain available for existing integrations.
