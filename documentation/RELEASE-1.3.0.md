# Kleyos 1.3.0

Cette version réunit les deux usages de Kleyos dans une famille unique,
**Kleyos Regular**, avec un TTF et un WOFF2. Elle reprend les contours,
les métriques et le crénage d’i33 Display. Elle étend la couverture à
334 points de code et inclut Google Fonts Latin Core.

Le ZIP comprend les fontes, la feuille CSS, le maître UFO 3, les
instructions de build, la licence et les rapports de vérification.
L’empreinte SHA-256 permet de contrôler le téléchargement.
